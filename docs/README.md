# 遊戲截圖

## 如何添加截圖

請將以下截圖放置在此目錄：

1. **screenshot-menu.png** - 主選單畫面
   - 應包含兩隻貓咪（橘子和阿灰）
   - 顯示「貓咪二段式剪刀石頭布」標題
   - 顯示「開始遊戲」按鈕

2. **screenshot-gameplay.png** - 遊戲進行中的畫面
   - 可以是選擇手勢的畫面
   - 或是結果公開的對戰畫面

## 建議尺寸

- 寬度：1280px（遊戲原始解析度）
- 高度：720px
- 格式：PNG

## 如何截圖

### 方法 1：從網頁版截圖
1. 訪問 https://catduel.vercel.app
2. 使用瀏覽器的截圖工具或按下系統截圖快捷鍵
3. 將圖片保存為 `screenshot-menu.png` 和 `screenshot-gameplay.png`

### 方法 2：從 Godot 編輯器
1. 在 Godot 中運行遊戲（F5）
2. 在想要截圖的畫面按 F12
3. 截圖會保存在專案根目錄
4. 重命名並移動到 `docs/` 目錄
